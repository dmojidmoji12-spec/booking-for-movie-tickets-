# Movie Booking JavaScript App

A beginner-friendly movie booking application built with HTML, CSS and JavaScript.

## Features
- Movie booking card
- Seat selection
- JavaScript validation
- Booking success message
- Close button
- Fallback redirect when the browser blocks window.close()

## Run
Open `index.html` in a browser.

## Important
Browsers generally do not allow JavaScript to close a normal tab that the user opened manually.
`window.close()` works reliably for windows/tabs opened by JavaScript.
